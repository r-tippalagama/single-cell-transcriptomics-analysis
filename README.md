single-cell-transcriptomics-analysis: Phenotype and kinetics of Mtb-specific T cells
This repo contains all the scripts that were used to perform transcriptomic analysis in single-cell data

Overview
Analysis of CD4+ HLADR+/- cells sorted from PBMCs of TB and healthy donors using R to characterize Mtb-specific T cells in TB disease. Includes QC, integration, clustering, and functional interpretation.

Key Findings
Identified Th cell clusters with distinct transcriptional signatures that seperates TB and healthy individuals. Majority of Mtb-specific T cells in TB had a Th1* phenotype
In healthy Mtb-infected individuals Mtb-specific T cells had a Th1 phenotype
Mtb-specific T cells phenotypes remained relatively stable over time with treatment progression
Methods
Platform: 10x Genomics
Processing: Seurat v4
Analysis: TCR gene aggregation, clustering, DE, trajectory analysis, TCR mapping.
